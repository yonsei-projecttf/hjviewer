With Auto Login ticked in the "OS Password" window, the app now enters the Windows password into a PC with HJViewer 1.9.3 or later only while that PC shows its sign-in or lock screen, never into an unlocked PC's open window. When you download files, this device checks the file and folder names the PC sends: nothing is written outside the folder you download to, and no file is replaced without asking. Downloading a file again after a cut-off download asks "A download of this file was cut off. Start it over?"
